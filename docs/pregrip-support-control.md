## Rail interface: prerequisite, not an installed carriage

Official [2025 starter-bot instructions](https://docs.revrobotics.com/frc-kickoff-concepts/2025/build-guide), steps39–43, use MAXLift blocks with2x1 tube/endcaps and an opposing stage. One REV-21-2618 block is not a proven captive linear rail. The proposed38.175mm backing web cannot simply be declared compatible.

The next native mating step is REV-21-2618 with standard REV-21-2710 endcaps and REV-21-2162 tube, then opposed bearing contacts, longitudinal separation, stops and60mm engagement. No such mating or attachment to this web has yet been executed. The source interface record explicitly remains blocked.

It requests gate opening only after that dwell and permits feed only after open feedback. Closing/opening deadlines and force/travel windows are hypothetical policy values, not hardware specifications.

Tests retain unilateral/no-contact, initially stuck-high, stale/replayed/nonfinite observations, missing gate feedback and post-release grip-loss controls.
