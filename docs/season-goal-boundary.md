# Season-goal boundary: transport is not scoring

This milestone connects the three distinct teaching objectives to executable event contracts. It does not turn the shared catcher into three completed scoring robots. The goals are fixed-location NOTE SPEAKER delivery (2024), bounded low-level CORAL L1 placement (2025), and availability-aware FUEL HUB delivery (2026). These are bounded prototype slices, not claims of optimal strategy or selected hardware.

## What now executes

`season-goal-boundary.mjs` separates release permission, independently supplied target evidence, and conditional component points. Unknown possession, alignment or mechanism readiness holds release. CORAL additionally uses a conservative REEF-zone release gate; this is a design policy, not a complete interpretation of whether any particular ejection is launching. FUEL consults the existing nominal phase model at release, then separately assesses arrival. A release during an active period can arrive in an unsupported transition/grace interval.

Nineteen tests cover three positive hypothetical target fixtures, absent target evidence, false/unknown inputs, CORAL support/contact exclusions, NOTE missing sensor and amplification, cross-piece/attempt/goal substitution, duplicate events and invalid/reversed/cross-period timestamps. These are software-interface tests, not physical sensor validation.

The existing diagnostic world receipt supplies 66 transport observations, including nine local model releases. All 66 retain unknown target criteria and unknown score in the new coverage report. The prior rig's local reverse exit is not a modeled launcher or trough placement. That receipt was imported, not relabeled as a new Java execution. Nine separately named target fixtures demonstrate the new interfaces and cannot be confused with plant-generated target events.

## Distinct rules and next physical step

**2024 SPEAKER:** the source criterion requires passage through the field-facing opening and sensor array. The adapter supports only interior-period, explicitly unamplified events (5 AUTO / 2 TELEOP nominal component points). Amplification and post-period assessment windows remain unsupported, not impossible. Next physical work is a launch-exit state with speed, orientation and spin, target-frame registration and field-opening geometry; the catcher exit cannot supply these implicitly. [2024 manual, 6.5.1 and 6.5.6](https://firstfrc.blob.core.windows.net/frc2024/Manual/HTML/2024GameManual.htm).

**2025 CORAL L1:** a hypothetical contact snapshot qualifies only with no same-alliance robot contact, no other-level scoring, and either trough contact or direct support by a CORAL contacting the trough. The interface preserves unknown contact separately from false and supports conditional 3 AUTO / 2 TELEOP component points. It does not implement ongoing score removal/restoration. Next physical work is trough geometry, end-effector pose and robot-contact separation during placement, not launcher flight. [2025 manual, 6.5.1, 6.5.4 and G412](https://firstfrc.blob.core.windows.net/frc2025/Manual/HTML/2025GameManual.htm).

**2026 FUEL HUB:** the existing TU22 assessor remains authoritative for this limited software slice, requiring top-opening and sensor passage and keeping grace/cross-phase cases unsupported. Next physical work is a launch trajectory to the HUB plus a passage/sensor model and flight-time-aware feed policy. A one-pocket experiment does not represent hopper throughput. [2026 manual, 6.4.1 and 6.5.1](https://firstfrc.blob.core.windows.net/frc2026/Manual/HTML/2026GameManual.htm).

## Evidence boundaries

Official HTML source hashes are retained from the retrieved season snapshots; they do not authenticate real match applicability. The deterministic report binds the adapter, existing FUEL assessor, evidence ledger, fixture input and imported transport receipt. All physical linkage is still marked not demonstrated. Full match totals, penalties, ranking, target contact calibration, complete robot compliance and engineering acceptance remain blocked.

The braked-guide candidate and its 250 ms failures are unchanged. Actual guide/tube assembly, belt anchorage, brake arrest dynamics and chassis envelopes remain separate work, not waived because the event contracts pass.
