# Write the strategy brief

Start with the [reviewed rules model](project-rules-model.md) and an observation saved from the [field rehearsal](field-rehearsal.md). Name the opportunity, robot start, available supply, scoring window, intended route and fallback. Trace the proposed action to its governing source and conditions.

Compare two feasible roles under the same clock and inventory. State how many pieces arrive in the window, how many the team can reach, points per delivery and target capacity. Subtract travel, handling, waits and recovery to estimate attainable throughput. Show which assumption changes the preferred role.

For each promising role, record the envelope, maneuver, acquisition or delivery rate, contact exposure, control states and operator cues it requires. For a contested lane, name the function that must survive contact and the loads still to be measured. Link an experiment, a success criterion and the responsible discipline to each uncertain capability.

Save the selected role, alternatives, owner decision, source revision and next experiment in the project. Carry requirements into the [subsystem contract](subsystem-contracts.md).
