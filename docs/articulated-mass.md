# Compare the mass moving with one joint

Before sizing an actuator or adopting a simulated cycle time, check which physical articles the simulator moves when one coordinate changes. A motor case carried by a slide translates with it. The same case stays fixed when its output shaft turns. Run the comparison separately for both coordinates with the other axes held at known positions.

Start at the current Fusion register. Use [native joint and moving-member observations](mesh-correspondence.md#choose-when-to-observe-a-joint) for signs and ownership, and [constituent material and mass reconciliation](engineering-material-mass.md) for the exact placed stock. Export the simulator's compiled inertial bodies, transforms and coordinate ownership independently. For a lumped inertial body, list each physical occurrence that it covers. Keep a bought article's total mass and child estimates from entering the same sum twice. Protect both input records with file hashes before comparing them.

```sh
python examples/mechanical-readiness/articulated-mass.py artifacts/mass-example
python scripts/articulated_mass.py artifacts/mass-example/matched.json
python scripts/articulated_mass.py artifacts/mass-example/swapped.json
```

The synthetic fixture has four equal blocks centered on two diagonals. Each diagonal has mass 0.012 kg, the same center, and 0.0000305 kg·m² about the shaft. The second run assigns the opposite two blocks to the turning shaft. The numerical checks still match. The four membership discrepancies identify the correction the simulator needs. Both commands print observations as JSON. Inspect `status` for `matched`, `mismatch` or `open`. A command error signals invalid or stale inputs.

**Commission a design case.** Use the example's `reference` and `simulation` file bindings. Both inputs identify the same issue digest, configuration, common frame, joint and held state. Pin the actual design issue in `reference.issueFile` and each input's underlying evidence in `sources`. Supply an explicit positive unit axis, axis origin in metres and signed configuration coordinate in radians for rotary or metres for prismatic travel. Transform local tensors and centers into the common frame before supplying them. A rotation transforms a centroidal tensor as R I Rᵀ. A reversed axis has identical projected inertia, so verify its sign separately. Set tolerances from the intended comparison.

**Select physical properties.** Identify every member by its resolved occurrence. Each reference member has `role` (moving, fixed or unknown), `massKg`, and `massBasis` (measured, supplier-nominal, density-model, model-assumption or unknown). Supply its `centerM` and, for a rotary coordinate, its centroidal tensor in kg·m² or `centroidalAxisKgM2` already projected along that axis at its own center. For a homogeneous solid, the checker can calculate both directly from the canonical placed STEP. Pin `step` in the reference and include that file in `sources`, then supply the member's `homogeneous: true` and `solid: {name, identity}` from the [exact placed-solid index](mechanical-methods.md#recheck-named-pairs-from-a-large-parked-step). The identity includes definition, instance and full occurrence path. This option uses OpenCascade and scales the integral by the specified mass. A single envelope for a motor or bearing with unknown internal distribution requires unknown properties or an independently justified partition.

**Read the result.** Compare roles for all members and record each simulated contributor's own mass basis; `contributingIds` identifies exactly which simulated moving members contribute to its reported mass, center, and rotary inertia. For each comparably covered mass, the calculation adds its centroidal projection and the mass times its squared perpendicular distance to the pivot line. Use `null` for unknown physical properties, state missing articles in `omissions`, and retain the known subtotal and its basis. A partial center describes only that subset. A prismatic joint has a translational mass and no rotary inertia result. A match expresses agreement between the supplied model inputs within the declared scope. Use the corrected model for [actuator duty and timing](actuator-duty-review.md); physical load capacity, added reflected rotor inertia, flexible stock and operation beyond the registered configuration require their own evidence.
