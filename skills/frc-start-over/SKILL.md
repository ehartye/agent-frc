# Start over on a robot design

1. Name the decision, outgoing scope and successor intent. If the team is still comparing alternatives, use `frc-whole-robot-design` to resolve that choice first.
2. Stop work on the outgoing design, coordinate any active CAD jobs, and gather its high points, images, failed checks and lessons. Pin the actual native source, tests and useful individual elements. Preserve unpublished and restricted evidence privately.
3. Run the [numbered cutover](../../docs/design-iterations.md). Hand every contributor the single active pointer. Begin with a blank working directory and a new Fusion design, including when only one subsystem prompted the restart.
4. Select reuse one item at a time. Manually insert or rebuild the selected element, record its provenance and reason, then rerun the interface checks imposed by its new surroundings. Continue daily work exclusively under the current iteration. Keep the previous public showcase until a replacement clears review.
