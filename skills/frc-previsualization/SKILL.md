# Rehearse a design in the space it will occupy

For a new game, extract the [project rules model](../../docs/project-rules-model.md) and build the [interactive field lab](../../docs/kickoff-field-lab.md). For an existing design, recover the selected cycle and current candidate through [design continuation](../../docs/strategy-first-continuation.md).

1. Start with a movable robot box, its bumpers and the cited field geometry. Show units, origin, assumptions and incomplete geometry. Let students change width, heading and height before adding mechanisms.
2. Assign each alliance a start and behavior in the [field rehearsal](../../docs/field-rehearsal.md). Try the same scoring window with a competing route. Save the obstruction, time lost and envelope for each trial.
3. Mark a source-to-target cycle. Account for loaded and return trips, pickup, staging, release and recovery. Use the opportunity calculation to determine the minimum sustained rate. For a batch, trace which packed pieces can reach the receiver and what resets between them. [Check storage and handoff cadence](../../docs/storage-to-service.md).
4. Link each reservation of volume to a requirement. Compare stowed, moving, deployed and service envelopes. A reversible chassis cut must identify the frame and bumper support it affects and the load-path check it requires.
5. Carry a saved observation into the student's match story. Use the [editable design artifact](../../docs/design-artifact.md) to preserve the chosen geometry, alternatives and open questions. Hand off frames, units, pose, revision and the next verification step to CAD.


Use [complete match rehearsals](../../docs/match-series.md) to test likely per-period behaviors for both alliances with finite piece stock, occupied robot footprints and explicit target activity. Compare the independent matches at 10× and carry observed queues and unresolved scoring conditions into the project strategy.

In each scoring opportunity state where the supply is, which pieces are already aboard and when loaded travel can begin. Use the loaded-batch screen for a single later transfer and preserve the assumption in the student narrative.
