# Original engineering worksheets

[![Original teaching swerve module rendered in Fusion](../examples/swerve/assembly.png)](../examples/swerve/independent-swerve.f3d)

*Plugin teaching example · Independent-axis swerve module, as saved in Fusion.*

Blank lesson templates only; no measurements, inspection results or private team data are bundled. Keep status not-performed until supported by evidence. Use the relevant skill to choose sources and version scope.

Navigation, device and mechanism-case worksheets are blank evidence templates. Distinguish source-supported observations, synthetic execution and physical measurements. Never enter credentials or student/team-private data.

Battery evidence and command lifecycle templates separate source identity, arithmetic, scheduler observations and physical evidence. They contain no real student/team data.

[Electrical evidence review](../docs/electrical-review.md) and its [blank worksheet](electrical-review.csv) distinguish component identity, terminal preparation, telemetry validity and hypothetical calculations.
