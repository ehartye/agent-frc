# Review a design continuation

Use this exercise to check what a reader actually retrieves when an existing investigation resumes through a skill. The reader and grader use separate material. The tabletop game and all project records are fictional.

## Run the exercise

Give a fresh reader the directory `examples/continuation/project/`, one skill entry point and the prompt **What should we try next?** Let the reader inspect that directory and follow the selected skill's guidance. Keep this grader outside the reader's materials. Save the answer and the paths actually opened. When comparing revisions, use fresh readers with the same prompt, entry skill and identical project files. Record the two plugin revisions.

## Grade the response

Record each observation as met, missing or contradicted. Grade discovery from the opened paths and citations. Grade the decision from what the answer recommends.

| Observation | Evidence to look for |
|---|---|
| Strategy and terms | The exchange-to-slot cycle and diagonal jam explain why orientation at the carrier matters. Straight and corner describe the partner's approach to the same throat. See `project/strategy/match.md`, S3, and `project/design/carrier.md`, D4. |
| Current route and alternatives | D4 uses a fixed V throat and belt. D1's rotary scoop is historical. The BOTH sketch is an unselected comparison. See D4 and `project/design/archive/receiving-arm.md`, D1. |
| Owner intent | Session 05 resolves session 03's open choice in favor of straight entry first. A future corner pass is the owner's tentative explanation for the cheek. Cite `project/notes/05-review.md`. |
| Rule constraint | Cite `project/rules/yard-manual.md`, Y1 revision 4, E2. Look for a way to observe the moving parts relative to the exchange plane throughout the trial. |
| Prior evidence | Empty belt travel in `project/bench/04-carrier.md`, B4, establishes one isolated motion. Loaded transfer, orientation and jam recovery remain open. |
| Experiment | Try a loaded straight entry with centered and deliberately offset handoffs. Observe carrier orientation or jamming and plane clearance. Describe what result would change the next design decision. The trial addresses receipt and centering during this cycle. |

A reader may propose a different discriminating test if it honors the selected route, exposes the same evidence gap and states an observable outcome. Record omissions or overclaims explicitly. A successful walkthrough establishes behavior on this project and prompt.

## Repeat with missing evidence

Prepare a separate copy of the project that omits only `notes/05-review.md`. Keep the reader blind to the original run and expected answer. Session 03 now leaves one consequential choice unresolved. The reader can locate the cycle, candidate, exchange-plane limit and baseline, then prepare a shared plane datum and orientation observation for either route. The approach stops depend on which pass to try first. The answer should ask which alignment the owner wants first, cite the unresolved decision, and avoid inventing an order.

For a rule-source check, instead omit only `rules/yard-manual.md` in another copy. The owner's straight-pass decision still stands. A good answer identifies the missing rule and bounds conclusions about legality pending retrieval of the applicable clause.
