# Navigation laboratory — WPILib 2026.2.1

Run the existing pinned project: gradlew.bat test headlessDemo. [NavigationTest](src/test/java/org/agentfrc/lesson/NavigationTest.java) adds nine original regression tests. [TrajectoryLab](src/main/java/org/agentfrc/lesson/TrajectoryLab.java) integrates an ideal differential-drive kinematic plant; [PoseEstimatorLab](src/main/java/org/agentfrc/lesson/PoseEstimatorLab.java) demonstrates an explicit timestamp/reset/outlier policy.

The generated path constrains reference wheels to 1.5 m/s; feedback requested 1.781 m/s. A separate 3 m/s output cap is a lesson fixture. 182 steps produced about 0.000590 m translation and 0.002813 rad heading error. These ideal values are not robot accuracy. No motors, traction, collisions or field geometry are modeled.

Estimator tests distinguish capture/arrival timestamps, reproduce out-of-order correction loss, verify actual reset encoder baselines and field Y travel at 90°, reject invalid/future/stale/duplicate/pre-reset frames and show bias reduction 0.20 m→0.11 m with delayed vision. The raw pinned estimator lacks explicit future/outlier rejection. The wrapper conservatively rejects non-increasing accepted timestamps rather than implementing multi-camera reordering. Its 0.5 s/1 m/30° thresholds are synthetic and uncalibrated. Wrong but plausible frame transforms can still pass.

Exercises: change one fixture parameter and predict the outcome before rerunning; record reference versus applied peaks; deliberately use arrival time; compare ordered/late frames; trace reset epoch and nonzero encoder baseline. Record evidence in the [worksheet](../../worksheets/navigation-evidence.csv). The worksheet link is relative to this lesson.
